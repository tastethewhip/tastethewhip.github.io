Sporting Life Results Scraper

v1.0.1

Scrapes UK/IRE (and international) horse racing results from sportinglife.com, with history going back to about 2004–05. It also pulls racecards for today, tomorrow and up to six days ahead.

Download the package View the repo on GitHub

What it does

  • Results for any date range, one row per runner or per race.
  • Racecards with draw, form, OR, jockey, trainer, odds, Timeform stars, Spotlight verdicts and last three runs.
  • Breeding: sire, dam and damsire from each horse's profile, cached for good.
  • Flexible CSV export: pick, reorder and rename columns; add blank columns to line up with other sheets.
  • Racing Post layout: one click matches the rpscrape column order so the two sources can be joined.
  • Built-in viewers for very large CSVs and SQLite databases, plus CSV joining and CSV → SQLite.
  • Polite by default: requests are spaced at least 0.5 s apart and raw data is cached, so rescrapes are quick.

Quick start

Needs Python with Tk (sudo apt install python3-tk on Ubuntu/Debian). Put the release files in one folder (or clone the repo), then:

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# desktop app
python gui.py

# results and racecards from the command line
python sl_results.py --from 2026-10-01 --to 2026-10-07 --uk-ire
python sl_racecards.py --tomorrow --uk-ire

Full setup notes, including pyenv, are in the README. Released under the GPL-3.0 licence.
